# Free tool 1: Merchant-of-Record Fee Calculator

**Positioning:** "What will I actually take home?" Compare Polar, Lemon Squeezy, and Gumroad net payout per sale and per month. It runs entirely client-side as a single HTML file (no backend, no API cost).
**Audience:** indie devs choosing a payment platform. This is the same audience as Products 1 and 3.
**Price:** free (lead magnet). CTAs link to Product 1 (starter kit) and Product 3 (P&L sheets).
**Polar notes:** none at runtime. CTA hrefs get swapped for Polar checkout links once the products exist.
**Fee assumptions** (from the plan's sources, Sep 2026; recheck before launch): Polar 5% + $0.50 (+1.5% intl); Lemon Squeezy 5% + $0.50; Gumroad ~12.9% + $0.80.
**Deploy:** static file on Vercel or GitHub Pages, only with Bradley's approval.
