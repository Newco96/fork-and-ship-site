# Fork & Ship — landing site + free tools

Static site (no build step, no analytics, no cookies). `index.html` is the landing page; `tools/` holds the two free tools (MIT, see LICENSE).
Checkout is handled by Polar Software, Inc. as merchant of record. The kit's Buy buttons use the production Polar checkout link (approved Oct 13, 2026). Polar returns buyers to `/?purchase=success`, which shows a thank-you message.
No secrets live in this repo.
